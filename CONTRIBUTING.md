# Contributing to WMS

Thank you for your interest in contributing to the Warehouse Management System (WMS)!

## How to Contribute

1.  **Report Bugs**: Use GitHub Issues to report bugs. Provide as much detail as possible, including steps to reproduce.
2.  **Suggest Features**: Open an issue to discuss new features or improvements.
3.  **Submit Pull Requests**:
    *   Fork the repository.
    *   Create a new branch for your feature or fix.
    *   Ensure your code follows the project's style (Frappe/Python).
    *   Add tests for any new functionality.
    *   Submit a PR with a clear description of the changes.

## Development Setup

Follow the installation instructions in the [README](README.md).

## Code Style

- Use PEP 8 for Python.
- Follow Frappe framework best practices.
- Document new DocTypes and functions.
